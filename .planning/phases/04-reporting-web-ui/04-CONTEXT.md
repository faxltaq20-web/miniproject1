<decisions>
## Implementation Decisions

### Verdict Generation — Hybrid approach
- **R-01:** The verdict block in the PDF has two parts:
  1. **Summary paragraph (2–3 sentences)** — generated by Gemini during report generation.
     Gemini receives the layer scores + top issues and writes a natural, paper-specific summary.
  2. **Recommendation line** — always rule-based from the final grade. NEVER Gemini-generated.
     Exactly one of four fixed strings (no variation allowed):
     - `"Recommendation: Ready for Submission"` (grade A)
     - `"Recommendation: Minor Revision Required"` (grade B)
     - `"Recommendation: Major Revision Required"` (grade C)
     - `"Recommendation: Not Suitable for Submission"` (grade D or F)
- **Rationale:** Gemini writes the paragraph so it feels tailored; the recommendation line is
  rule-based so format is always consistent regardless of how Gemini words the summary.

### API Design — Two endpoints
- **R-02:** `/analyze` (existing) continues to return JSON — no changes.
- **R-03:** New `/report` endpoint added to `main.py`:
  ```
  POST /report
  Body: JSON (the full /analyze response body)
  Response: StreamingResponse, media_type="application/pdf"
  Header: Content-Disposition: attachment; filename="{filename}_report.pdf"
  ```
- Frontend flow: user uploads PDF → `/analyze` returns JSON → UI displays results →
  user clicks "Download Report" → frontend POSTs the JSON to `/report` → PDF downloads.
- **R-04:** `/report` does NOT re-run Gemini analysis or CrossRef — it only generates the PDF
  from the data already computed. The one extra Gemini call (verdict paragraph) IS acceptable
  and happens inside `report_generator.generate_pdf_report()`.

### Marks Display Conversion
- **R-05:** `report_generator.py` handles all marks conversion internally.
  Formula: `earned_marks = round(gemini_score_0_to_10 * max_marks / 10)`
  - Grammar (max 15): score 8 → `round(8 * 15/10)` = 12 → displays `12 / 15`
  - Readability (max 10): score 7 → `round(7 * 10/10)` = 7 → displays `7 / 10`
- No changes to `scoring.py` or any other existing module.

### PDF Section Order
- **R-06:** Section order in the PDF (Score-first / Option A):
  1. Header (title, filename, analysis date)
  2. Overall Score (grade-coloured table)
  3. Parameter Breakdown (all 8 parameters with marks, issues, suggestions)
  4. Citations (summary line + flagged DOIs only)
  5. Verdict (Gemini paragraph + recommendation line)

### ReportLab Implementation (from desirable.md — already locked)
- **R-07:** Library: ReportLab **PLATYPUS** — `SimpleDocTemplate` + flowable objects
  - Flowables used: `Paragraph`, `Table`, `Spacer`, `ListFlowable`, `HRFlowable`
  - Automatic page break handling — critical for variable-length parameter sections
- **R-08:** Page: A4, 2cm margins all sides
- **R-09:** Fonts: `Helvetica` (body), `Helvetica-Bold` (headings) — built-in, no external fonts
- **R-10:** Accent colour: `#1a73e8` for section headings
- **R-11:** Score block background fill by grade:
  - A → green `#34a853`
  - B → blue `#1a73e8`
  - C → amber `#f9ab00`
  - D or F → red `#ea4335`
- **R-12:** Page footer on every page: page number + "Generated by ResearchSense"
- **R-13:** Output: `io.BytesIO` buffer — **never written to disk**

    filename: str,

<code_context>
## Integration Contract

### /report endpoint in main.py
```python
from fastapi.responses import StreamingResponse
import report_generator  # Phase 4

@app.post("/report")
async def generate_report(analysis: dict):
    """
    Accept the full /analyze JSON response and return a PDF report.
    Does NOT re-run Gemini analysis or CrossRef validation.
    """
    buffer = report_generator.generate_pdf_report(
        filename=analysis["filename"],
        layer_scores=analysis["layer_scores"],
        layer_details=analysis["layer_details"],
        final_score=analysis["final_score"],
        grade=analysis["grade"],
        citation_result=analysis["citation_result"],
    )
    buffer.seek(0)
    safe_name = analysis["filename"].replace(".pdf", "")
    return StreamingResponse(
        buffer,
        media_type="application/pdf",
        headers={
            "Content-Disposition": f'attachment; filename="{safe_name}_report.pdf"'
        }
    )
```

## Specific Ideas

- Use `KeepTogether([heading, first_bullet])` to prevent parameter headings from being
  orphaned at the bottom of a page with content on the next
- The citations section only shows `not_found` DOIs — do NOT list verified DOIs
- If `citation_result["total_dois"] == 0`: citations section shows "No DOIs detected in references"
- If `citation_result["flagged_dois"]` is empty but total > 0: show "All N DOIs verified ✓"
